The GPS's one-line excuse for make.fun's "The GPS Swears It Was a Shortcut" bounty: a program that writes a single line (163 characters) in the GPS's own smug, defensive voice, blaming the map for a cul-de-sac shortcut that ended at a wedding — and insisting it technically delivered the driver somewhere. One line, no setup, no dialogue tags, just the excuse.

## Run it

```sh
node main.ts
```

Writes the excuse to `/output/entry.txt`. Requires Node 22.18+ (TypeScript runs as-is). No network access is used at run time.
